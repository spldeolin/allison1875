## 创建支付

### URL

POST /api/payments

### Request Body (application/json)

| 字段名             | JSON类型       | 注释     | 其他                                                                          |
|-----------------|--------------|--------|-----------------------------------------------------------------------------|
| description     | String       | 支付描述   | 1. 必须有非空格字符<br>2. 最小长度/容量：1<br>3. 最大长度/容量：100                               |
| amount          | Number       | 支付金额   | 1. 不能为null<br>2. 最小值：0.01<br>3. 最大值：999999.99<br>4. 最大整数位数：6<br>5. 最大小数位数：2 |
| expectedPayTime | String       | 预计支付时间 | 必须是未来                                                                       |
| count           | Int(32)      | 支付笔数   | 必须是正数                                                                       |
| tags            | String Array | 标签列表   | 1. 列表内元素必须有非空格字符<br>2. 列表内元素最小长度/容量：0<br>3. 列表内元素最大长度/容量：20                 |

### Response Body (application/json)

| 字段名    | JSON类型  | 注释   | 其他 |
|--------|---------|------|----|
| id     | Int(64) | ID   |    |
| amount | Number  | 支付金额 |    |
| status | String  | 状态   |    |
